# Identidad visual — propuestas

Este documento guarda **propuestas**. El equipo de frontend decide y puede cambiarlo todo.

## Nombre y frase
- Nombre: **TEPEXA** (marca inventada inspirada en el náhuatl *tepētl*, «cerro»; no es una
  traducción náhuatl).
- Frase: **Explore the Unknown / Explora lo desconocido** — pantalla de entrada y pie del
  informe.

## Paleta
La paleta oficial está en el logo del equipo. Pendiente: pasar los valores HEX a este
documento cuando el logo esté en el repo. Propuesta previa (referencia, no decisión):
Obsidiana Mineral `#111B20`, `#304D49`, `#A2C8B1`, `#D0E67A`, `#F1EDE3`.

Las capas científicas usan escalas de color propias con leyenda; la marca no debe alterar
la lectura del mapa.

## Tipografía (propuesta)
IBM Plex Sans para la interfaz e IBM Plex Mono para datos y telemetría (licencia abierta).

## Conceptos de pantalla (propuesta)
1. **Consola mineral (PC):** fondo oscuro con curvas de nivel tenues, datos en monoespaciada,
   acento solo para la ruta activa.
2. **Atlas de campo:** fichas de puntos de interés como etiquetas de muestra geológica; el
   perfil de elevación como corte topográfico.
3. **Visor de casco (simulador y móvil):** paneles translúcidos con telemetría, brújula,
   minimapa y el avatar de Rive del tripulante.
4. **Entrada:** video de animación automático con el globo (lo produce el equipo en Blender).

Evitar: cohetes, planetas con anillos y neones.
